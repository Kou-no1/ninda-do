# 忍打道 —NINDA DO—

型（かた）をきわめた者だけが、疾風（はやて）をゆるされる。——それが、忍打道。

公開URL: https://kou-no1.github.io/ninda-do/

## 遊び方

1. `index.html` を開き、にんじゃネームを入れる。
2. 里で「修行」を選び、正しいキーを打つ。
3. 修行を1回終えたら「試し」を選ぶ。1級合格で下忍となり、「実戦の間」が開く。

## 先生向け調整ポイント

- 級ごとのキー、かな、合格基準、ガイド量: `data/curriculum-data.js`
- 段位試験のKPMや正確率: `data/rank-data.js`
- 語彙や文章: `data/words/*.js`
- 術と巻物: `data/jutsu-data.js`
- 二つ名条件: `data/nickname-data.js`
- 復習間隔・小修行・任務・読書解説: `data/learning-data.js`
- 名文アドバンスドの作品・カテゴリ・時間・監査状態: `data/literature-data.js`
- 巻物便の便・時間・点数・移動時間・分かれ道・身支度条件: `data/game-data.js`

ビルド工程はありません。GitHub Pages は `main` ブランチのルートをそのまま配信します。

## 記録と教具

設定の「バックアップをとる」は、キー統計・自己ベスト・成長記録を含む完全なJSONを出します。「ファイルからもどす」では差分確認後に復元します。短い合言葉は進み具合の簡易移行用で、詳細統計・番付の記録は含みません。

級の「にがてキーのふくしゅう」は、習ったキーだけを使い、速さを競いません。免状には直近の修行記録が並び、結果には前回の自分との比較が出ます。

設定から指色ポスターと先生の運指かくにん表を印刷できます。アプリは打鍵の正しさを判定しますが、実際にどの指を使ったかは測れません。観察チェックは先生が行い、児童の進捗には保存されません。

先生モードは設定のバージョンを10回操作し、教室用コードを入力して有効にします（ソース公開のため秘密情報ではありません）。デモ中は設定以外の進捗を書きません。

## 修行帳と巻物便

「きょうの修行」は、おさらい・今の型・小修行をえらべます。復習の間隔は1・3・7・14日が初期値で、実際の授業に合わせてデータで調整します。級では時間や速度を競いません。

修行帳には、ん・っ・拗音・キーの取り違えの小修行、失敗や欠席で灯りを失わない任務帳、キーごとの正確率、打ち終えた59本文の読書帳があります。読みやすさは、文字の大きさ・行間・指記号・動きの抑制を設定できます。

先生モードの「課題」では、級とお題を指定してJSONの課題巻物を作れます。児童はファイルを確認して取り込みます。未導入かな・キーや重複を拒否し、未解放の級の課題は開始できません。課題を終えても昇級や通常修行の試験ゲートを勝手に進めません。外部送信・本名・クラス名はありません。

1級を終えて下忍になると、「実戦の間」から新しいゲーム「巻物便」が開きます。里・山・月の3便で、ことばを打って巻物を届けます。門に着いてもお題は飛ばされず、打ち終えるまで待ちます。配送点と早着ボーナスの合計に正確率を掛けた得点を、自分のベストとして保存します。先生のデモは無記録です。

### 巻物便の道と分身

巻物便は里の屋根・竹林・山の橋を巡ります。ノーミス配送や連続正打で庭の近道が開き、ミスしても閉じません。「前回の道を、分身と走る」と結果の「もういちど」は同じお題順で再挑戦します。分身は自分の前回の配送だけで、他人との順位はありません。配送時刻だけを端末に保存し、打ったキー列は残しません。

修行帳の「身じたく」で、ずきん・おび・巻物ぶくろを着せ替えられます。正確な修行や復習で手に入り、得点・時間・キー判定は変わりません。先生は全種類を無記録プレビューできます。結果の「ししょうのひとこと」はその回のかな・キーのミスから選び、習った範囲の小修行へつながります。

修行帳の「同じお題」では、便とお題番号から共通お題の合言葉を作れます。先生から配られた合言葉を確認して、同じ順のお題に取り組めます。外部送信・名前・クラス情報・集計表はありません。下忍から使え、便の段位条件は通常どおりです。お題やルールが変わった版の合言葉・分身は使えません。これは進み具合を復元する合言葉とは別です。

## 名文アドバンスド

上忍になると「実戦の間」または修行帳の「書庫」から開けます。古典の入口・近代文学・俳句と短歌・詩のことばの4コースに、採用済みの28作品・抜粋を収録。作品と作者で選び、時間なしで収録分を打ち切る修行と、時間制の修行を分けました。作品内の順序、ルビ、出典を保ち、打ち切った範囲と正確率を読書帳に残します。作品全体を読了したという記録ではありません。

v1.12.1で金子みすゞ「私と小鳥と鈴と」「星とたんぽぽ」「不思議」の全詩、新美南吉「手袋を買いに」の抜粋、宮沢賢治「『注文の多い料理店』序」の冒頭四段落を追加しました。5作品・24お題で、詩の繰り返しはそのまま保持します。読書帳では重複する本文をまとめるため、旧36本文と合わせて59本文です。本文と採用判断は`IMPLEMENTATION_NOTES.md`に記録しています。今後の未採用候補はdataの`audit: "pending"`と`useReview`で除外します。

## 検証

```sh
node scripts/check-data-integrity.mjs
node scripts/check-system-regressions.mjs
node scripts/check-browser-regressions.mjs
```

最初の2本はNode18以上・依存0。ブラウザ検証はNode22以上とChrome/Edgeを使い、必要なら`CHROME_PATH`を指定します。独立した一時プロファイルで実行し、普段のセーブには触れません。証跡は表示された一時フォルダへ保存します。

調整後は全JS/MJSの`node --check`も実行してください。現行の統合仕様は`SPEC_FOR_CODEX.md`、全数値とスキーマは`_reference/`、判断と検証結果は`IMPLEMENTATION_NOTES.md`にあります。
