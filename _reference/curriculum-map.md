# curriculum-map

入門・壱 → 入門・弐 → 入門・参 → 入門・肆 → 10級 → 9級 → 8級 → 7級 → 6級 → 5級 → 4級 → 3級 → 2級 → 1級 → 下忍 → 中忍 → 上忍 → 特上忍 → 影

型の修行:

- 入門から1級までは速度表示なし。
- 10級から1級はキーとかなを段階的に解放する。
- 1級合格で免許皆伝、下忍、疾風の術を解禁する。

実戦の修行:

- 下忍以降のみKPM表示を使う。
- ことばの実戦、文章の実戦、疾風番付、弱点特訓を持つ。上忍から名文・古文の実戦が追加される。
- 昇段試験は型、実戦、心眼の三の試しを通しで行う。
